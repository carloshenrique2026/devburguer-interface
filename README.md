# OrderFlow

OrderFlow é uma plataforma Full Stack para gerenciamento de pedidos online, desenvolvida com React, Node.js e PostgreSQL.

A aplicação permite autenticação de usuários, gerenciamento de produtos e categorias, processamento de pedidos e integração com pagamentos online através do Stripe.

## Tecnologias

### Frontend

* React
* Vite
* Styled Components
* Axios
* React Router

### Backend

* Node.js
* Express
* Sequelize
* JWT
* Multer
* Stripe

### Banco de Dados

* PostgreSQL

## Funcionalidades

* Autenticação JWT
* Controle de acesso por perfil
* Gestão de produtos
* Gestão de categorias
* Upload de imagens
* Carrinho de compras
* Processamento de pedidos
* Integração com Stripe
* Painel administrativo
